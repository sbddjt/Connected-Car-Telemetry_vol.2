Velog 게시:
Markdown 본문을 편집기에 붙여 넣을 수 있습니다.
Velog는 이 PC의 로컬 이미지 경로에 접근할 수 없으므로, images 폴더의 원본 이미지를 업로드하고 각 이미지 참조를 Velog에서 생성한 주소로 교체해야 합니다.
HTML 복사만으로 이미지가 Velog 서버에 업로드된다고 보장하지 않습니다.
현재 결과물은 로컬 최종본이며 외부 사이트에 게시하지 않았습니다.
